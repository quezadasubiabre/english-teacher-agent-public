# UI Description

The UI has four zones:

## Top Bar
Two pills: the conversation topic (clickable to rotate through topics) and the user's level.

## Teacher Card
Circular avatar "ES" with a blue pulsing ring when speaking, name, text status ("Listening / Speaking / Not connected"), and a blue bar waveform that only animates when the teacher is talking.

## Transcription Card
"LIVE TRANSCRIPTION · YOU" badge with a blinking red dot, and the user's text appears character by character with a blinking cursor.

## Bottom Zone
Two stacked elements:

- A compact row (visible only when connected) with a small microphone icon on the left and the user's teal green waveform on the right. The mic doubles as a mute button.
- The large centered call button (green → pulsing amber → red) with a label and session timer below.
